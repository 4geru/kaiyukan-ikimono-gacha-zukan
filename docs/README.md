# docs

| 場所 | 中身 |
| --- | --- |
| `submission/` | ハッカソンの提出物。システム構成図（`architecture-system.png`）、スライド（`slides/`）、数値の出典（`sources.md`）、友だち追加の QR |
| `specs/` | 機能ごとの仕様（要件・設計・作業リスト）。フォルダ名の番号は GitHub Issue の番号 |
| `research/` | 調べたことのメモ（駅すぱあと MCP、LIFF と Firebase の認証、関西の水族館など） |
| `charactor/` | カワウソ助教授とジンベエ名誉教授の設定と、掛け合いの例 |
| そのほかの `*.md` / `*.html` | 設計レビューや検討の記録（日付つき） |

アプリ全体の説明はルートの [README](../README.md) にあります。

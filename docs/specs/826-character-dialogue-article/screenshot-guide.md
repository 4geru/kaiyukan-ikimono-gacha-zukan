## 共通の準備

- 開発用の撮影専用 LINE アカウント（表示名・アイコンを汎用的なものに）を使い、iPhone 実機で撮る
- 質問文は個人情報・位置情報を含まない内容にする
- 隠す項目（単色の塗りつぶし。ぼかしは復元されうるので使わない）
  - 自分の表示名・プロフィールアイコン（トーク画面ヘッダ等）
  - トーク画面上部の Bot アカウント名が公開前の検証名ならそれ
  - ステータスバー（時刻・キャリア・通知）、他アプリの通知バナー
  - トークリスト・友だち一覧が写る場合はその部分
- 隠さない: Bot の返信に出るキャラの名前とアイコン（公開前提・隠すと意味がなくなる）
- 公開前: 画像メタデータ（位置情報など）を除去 → `images/articles/line-bot-sender-character-dialogue/` に連番で配置 → TODO コメントを `![説明](/images/articles/line-bot-sender-character-dialogue/1.png)` に差し替え

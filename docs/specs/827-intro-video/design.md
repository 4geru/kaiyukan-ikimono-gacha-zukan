# Design — 最終提出用 紹介動画（約3分）

## 1. 方針

- Remotion プロジェクトを `project-google-cloud-japan-ai-hackathon-vol5/video/` に新規作成する。aruaru-zukan の remotion から次をコピーして改変する（aruaru 側は触らない）
  - `scripts/aruaru/generate-system-voice.ts` の Gemini TTS 呼び出し（`ai.interactions.create`）と `trimSilence`
  - `scripts/aruaru/lib/redesign.ts` の Lyria BGM 生成（`generateBgm` の呼び出し部分のみ）
  - `src/compositions/aruaru/gacha/GachaBurst.tsx`（光の爆発→カードのズームイン）、`anim.ts`（mulberry32 / backOut）、`font.ts`（Noto Sans JP）
  - `public/aruaru-gacha/se/` の手続き合成 SE（reveal-jackpot / sparkle / pop。自作合成音なので権利問題なし）
- 原稿の正本は `video/config/script.json`。セリフ単位で `{ id, speaker, text, speak?, pauseAfter? }` を持つ。`speak` は読み上げ専用（例: LIFF→リフ、MCP→エムシーピー）で、字幕は `text` を出す
- `make voice` が全セリフを TTS → 無音除去 → `public/voice/<id>.wav`。実測 duration から `src/timeline.json` を書き出す。src 側はこの JSON を import するだけ（src は fs に依存しない）
- シーン長 = 頭の間 + Σ(セリフ長 + pauseAfter) + 尻の間。シーンごとの `minSec` を下限にする。合計が 170〜190 秒から外れたら原稿を直す
- 画面内のアニメは「シーン相対フレーム」と「セリフ開始フレーム（`lineAt(scene, idx)`）」で駆動し、ナレーションと絵の動きを同期させる
- CSS アニメーション禁止（`useCurrentFrame` + `interpolate` / `spring` のみ）。粒子は固定 seed

## 追加: 新規性パート（2026-10-08 ユーザー指示）

### 伝えること（ユーザー指定の3点）
実際の魚を撮るのではなく、**解説パネルを撮る**ことが今回の新規性。
1. 解説パネルには魚の名前が書いてあるので、見分けの間違いが少ない
2. 撮るために解説を読む習慣がつく
3. パネルで知った魚を、実際の水槽で探す体験ができる

### 置き場所
S2 届けたい人（課題: 解説は文字が多く、子どもは読む前に次の水槽へ）と S3 撮る→わかる（使い方）の間に、新シーン **S2.5 novelty「撮るのは、魚ではなく解説パネル」** を挟む。流れは「課題 → アイデア（新規性）→ 実演」。審査観点タグは「新規性・有効性」。

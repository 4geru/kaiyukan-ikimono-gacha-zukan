# さかなクン画風リサーチ（ガチャカードイラストの方向性）

ガチャカードのイラスト生成（Gemini 3 Pro Image / Nano Banana Pro）のプロンプト設計に使うため、さかなクンのイラストの特徴を言語化してまとめる。

## 前提・注意

さかなクンのイラストそのものは本人・運営会社に著作権があり、公式サイトの「イラスト集」も転載不可と明記されている。ここでやるのは**実在作品の模倣・トレースではなく、画風の特徴を一般的な言葉に言語化して、別のオリジナルイラストのスタイル指定として使う**こと。生成物に「さかなクン画」「さかなクン風」等の本人名を明示的に付与・混同させる使い方はしない（本人になりすます・実在作品と誤認させる表現は避ける）。

## 特徴のまとめ

### 画材・技法
- 水性・油性のカラーペン、筆ペンなど身近な画材を使ったミクストメディア
- デジタルではなく手描き感のある線・塗り

### リアルさとデフォルメの絶妙なバランス
- 図鑑並みに緻密で正確な観察に基づく解剖学的特徴（ヒレの形・体のライン・模様など、実在の生きものとして破綻しない正確さ）
- その上で、生き生きとした表情や動き（今にも泳ぎ出しそうな躍動感）を加える
- 擬人化された豊かな表情（ユーモラス・愛らしい・どこか人間味がある）が持ち味

### タッチの空気感
- 技巧よりも「魚への愛情が伝わる」素朴で親しみやすいタッチ
- 上手い下手という評価軸ではなく、観察と愛着に基づく説得力

## カード生成プロンプトへの反映方針

Nano Banana Pro（Gemini 3 Pro Image）に海遊館の実写（参考画像）を渡し、以下の方向性でイラスト化する:
- 手描きの色ペン・筆ペン風のミクストメディアタッチ（ベタ塗りのアニメ調ではない）
- 実在種として破綻しない解剖学的正確さ（参考写真のヒレ・体形・模様を尊重する）
- 生き生きとした表情・躍動感のある構図（図鑑写真の無表情な引きではなく、動きや表情を加える）
- 過度なリアル路線にも、記号的なゆるキャラ路線にも寄せすぎない、その中間の「素朴で愛らしい」トーン

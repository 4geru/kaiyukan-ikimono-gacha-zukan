# 関西の水族館: 緯度経度と最寄り駅

「現在地から最寄りの水族館」（[#789](https://github.com/4geru/tweet-bookmark/issues/789)）のマスタ元データ。調査日: 2026-09-19。使い方は [ekispert-mcp.md](ekispert-mcp.md)。

## データの出どころと精度

| 項目 | 取得元 | 注意 |
| --- | --- | --- |
| 緯度経度（WGS84） | 国土地理院 住所検索API（`msearch.gsi.go.jp/address-search/AddressSearch`）に各館の住所を投げた結果 | 番地の代表点であり、入口の位置ではない（数十m〜100m程度ずれうる）。町丁目までしか返らなかった串本海中公園は特にずれる |
| 直線で近い駅 | OpenStreetMap（Overpass API）の駅ノードとの直線距離 | 駅すぱあと MCP の出力**ではない**。MCP 接続後に `get_stations_from_geo` で照合する |
| 玄関口駅・アクセス | 各館の公式サイト・駅探・NAVITIME 等の検索結果 | 徒歩分数は情報源で差がある。バス連絡の館は直線で近い駅と玄関口駅が一致しない |

マスタの `station` には**玄関口駅**を使う（直線最寄り駅ではない）。

## 調査で分かったこと

- 滋賀は琵琶湖博物館（水族展示）のみ採用。奈良は今回の調査（水族館まとめサイト3件）では見つからなかった
- **初期の住所を2件誤っていた**（みなとやま水族館・加古川海洋文化センター）。公式・地図サイトの住所で直し、再ジオコーディングした。マスタ化するときは全館の住所を公式サイトで再確認すること
- 姫路市立水族館は 2026-03 に JR 手柄山平和公園駅が開業し、徒歩の目安が情報源で 9分（NAVITIME）/ 15分（公式）と割れている。駅すぱあと側に新駅が反映済みかは MCP 接続後に確認が必要
- 駅名が同じでも事業者が違う駅がある（例: 手柄山平和公園、湊川）。`search_routes` には駅コードで渡すほうが安全なので、マスタに駅すぱあとの駅コードを持たせる案を design で検討する
- 水族館まとめサイト（水族館.com・駅探）に載っていた施設を中心に選んだため、小規模施設の取りこぼしがありうる
